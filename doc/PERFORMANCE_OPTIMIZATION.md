# Оптимизация производительности слайдеров

## Проблема
Ранее слайдеры загружали все изображения одновременно при инициализации, что приводило к:
- Медленной загрузке страницы
- Высокому потреблению трафика
- Плохому пользовательскому опыту

## Решение
Реализована ленивая загрузка изображений (Lazy Loading) с использованием следующих подходов:

### 1. Хук `useLazyImage`
- Загружает изображение только когда оно становится видимым
- Использует Intersection Observer API для отслеживания видимости
- Поддерживает предзагрузку соседних изображений

### 2. Хук `useLazyImageArray`
- Оптимизирован для работы с массивами изображений
- Загружает первое изображение сразу для быстрого отображения
- Предзагружает остальные изображения в фоне с низким приоритетом

## Компоненты

### ImageSlider
- Загружает только видимые и соседние изображения
- Показывает скелетон во время загрузки
- Автоматически предзагружает изображения при смене слайда

### GenericSlider
- Использует Intersection Observer для ленивой загрузки
- Загружает изображения по мере прокрутки
- Показывает плейсхолдер для незагруженных изображений

## Преимущества

1. **Быстрая загрузка страницы** - загружается только первое изображение
2. **Экономия трафика** - изображения загружаются по требованию
3. **Лучший UX** - пользователь видит контент быстрее
4. **Масштабируемость** - работает эффективно с большим количеством изображений

## Настройки

### Threshold
- `0.1` - изображение начинает загружаться когда 10% элемента видно
- `0.5` - изображение начинает загружаться когда 50% элемента видно

### Root Margin
- `50px` - изображение начинает загружаться за 50px до появления
- `100px` - изображение начинает загружаться за 100px до появления

## Использование

```tsx
import { useLazyImageArray } from '../../hooks/useLazyImage';

const MyComponent = () => {
  const imageUrls = ['url1', 'url2', 'url3'];
  
  const {
    isImageLoaded,
    loadImageOnDemand,
    preloadImages
  } = useLazyImageArray(imageUrls, {
    threshold: 0.1,
    rootMargin: '50px'
  });

  return (
    <div>
      {imageUrls.map(url => (
        <div key={url}>
          {isImageLoaded(url) ? (
            <img src={url} alt="image" />
          ) : (
            <Skeleton />
          )}
        </div>
      ))}
    </div>
  );
};
```

## Мониторинг производительности

Для отслеживания эффективности оптимизации рекомендуется:

1. Измерять время до первого контента (FCP)
2. Отслеживать общий объем загруженных данных
3. Анализировать Core Web Vitals
4. Тестировать на медленных соединениях

3. **Progressive JPEG** - постепенная загрузка изображений
